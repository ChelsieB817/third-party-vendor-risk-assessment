# third-party-vendor-risk-assessment
GRC portfolio project evaluating google Workspace security controls through third party vendor risk assessment, security questionnaire development, evidence review,risk scoring and mitigation recommendations.
Project Overview
This project demonstrates the third-party risk assessment process used by Governance, Risk, and Compliance (GRC) professionals to evaluate the security posture of external technology vendors.

The assessment focuses on Google Workspace, a Software-as-a-Service (SaaS) provider, using publicly available security documentation to review security controls, identify potential gaps, evaluate vendor risk, and develop recommendations.

Assessment Objectives
Develop a structured vendor security questionnaire.

Evaluate vendor security controls across key security domains.

Research and document publicly available security evidence.

Apply a standardized risk scoring methodology.

Identify security strengths, weaknesses, and evidence gaps.

Develop risk mitigation recommendations.
